# Panda Dev — 3D Portfolio

Open `index.html` in a browser.

## What is included
- Responsive desktop + mobile layout
- Cinematic Dev Dojo visual foundation
- 3D-style card tilt and animated floating particles
- Tech stack section
- Featured project cards
- Developer workflow
- Interactive "Catch the Code Bugs" mini-game
- Responsive mobile navigation
- Contact / GitHub / LinkedIn placeholders

## Customize
Edit `index.html`:
- Replace project names/descriptions/tags
- Replace `hello@example.com`
- Replace GitHub and LinkedIn links
- Add your real tech stack and experience
- Replace `assets/dojo-hero.png` if you create a custom hero image
